# 真实课程副本的媒体兼容性检查

过去对 Z820 课程副本的检查主要覆盖素材存在、大小、引用及封面读取，无法回答视频能否起播和拖动、资料是否能打开。本 PR 增加可复跑的离线审计工具，并记录真实课程资产在实际阅读器组件中的有界浏览器检查。基于 PR #64 的 `feature/production-read-benchmark`（3483f3a），复用既有私有快照守卫。

`api/dev/audit-production-media.py` 只处理已完成、已绑定且权限符合要求的私有课程副本。它核对清单、配置和普通文件边界，用受限 ffprobe/pdfinfo 提取元信息，以固定错误码保留失败分母，并给出有界代表样本。报告使用匿名资产摘要，不写原路径、课程名、正文、凭据或探测器原始诊断。输出新增私有报告，既有资料不改写。详细接口、前置条件和限制见[作者记录](production-media-compatibility-author.md)。

用户指定 GPT-6.1-sol / ultra 子 Agent 并行编写工具、独立测试和只读浏览器辅助程序，主 Agent 执行真实副本与浏览器检查并整合；委派接口没有独立 Fast 参数。[独立测试](production-media-compatibility-tests.md) 33/33 通过，无跳过，覆盖清单与权限、符号链接、无效格式、资源上限、子进程回收、失败分母、前后变化和报告隐私。

## 真实副本结果

- 来源是 2026-10-03 已获取的 Z820 私有隔离副本，本次未重新访问或修改 Z820 生产服务。数据库 5 门课程、83 个单元，单元分布于其中 3 门课程，297 个课程资产共约 5.94 GB；学生附件未复制。
- 211/211 个媒体完成离线元信息/文本解析：83 MP4 均为 H.264 High 与单声道 AAC，时长约 51.63–558.63 秒；23 个 moov 在 mdat 前、60 个在后。45 PDF 页数 4–30，均未加密；83 Markdown 为有效 UTF-8。另 86 个 JPG/PNG 只核对清单，未做图片解码。
- 在当前候选 49bea7da 的真实 UnitViewModal/JModal 中，Chromium 154.0.8037.93 检查 5 个视频，覆盖两种 moov 布局、最长/最大样本和所有 3 门有单元的课程。全部完成元数据加载、实际帧解码与播放前进、拖至中段后继续、跳到末尾并结束、切换内容页卸载，以及重新播放后关闭卸载。
- 从真实阅读器资料链接打开 2 PDF（30 页和 9 页）：浏览器原生查看器首屏、部分正文和缩略图实际渲染，主 Agent 检查截图；未逐页检查。1 份最长行数 Markdown 按纯文本打开，5417 字节、326 行，浏览器文本 SHA256 与所选源文件一致。这不是 Markdown 富文本渲染验收。
- 8 个所选资产在提供给浏览器前完整计算 SHA256，均与获取清单相同。全部 297 文件的 stat 元数据和 7 张业务表行摘要在前后相同；未重新哈希全部 5.94 GB 文件。后端运行包绑定 `9eb18d42…`，前端产物清单仍为 #63 的 `0b38b469…`，本次没有重建或切换应用产物。
- 私有辅助服务 HEAD/Range、白名单和拒绝条件实测 19/19；本任务浏览器与 18188 服务已关闭，进程退出且端口连接被拒绝。原有产品与真实副本服务保留。

主要可分享证据见[结果汇总](evidence/production-media-compatibility/root-result.json)、[匿名样本绑定](evidence/production-media-compatibility/sample-bindings.json)、[视频观测](evidence/production-media-compatibility/browser-video-results.json)及[文档观测](evidence/production-media-compatibility/browser-document-results.json)。独立 Agent 复算了离线报告计数、分母、统计和样本理由；它没有重新执行浏览器，不能写成独立浏览器验收。真实正文、文件名、截图、临时 URL、selection 和浏览器日志只留本机私有目录 `.devspace/artifacts/real-media-browser-20261005`。

## 精确版本与限制

真实离线运行模块为 `b4bc6366…`，最终模块 `ad102c2c…` 仅增加一条“Markdown 标题计数不是完整语法解析”的报告限制字符串。主 Agent 和独立审阅均验证移除此行可精确恢复旧摘要；最终模块并未再次读取真实素材。最终工具测试在 ad102c2c 上通过。初次 18 项测试中两个自制测试夹具问题已修复；最初浏览器记录受 250ms 观察器延迟影响，操作等待条件通过但即时记录可能落后，原记录保留，随后以直接 HTMLVideoElement 属性重新完成 5 个样本。最终控制台只观察到辅助页 favicon 404。

浏览器使用实际阅读器源码和真实素材，但学习记录请求由内存成功适配，资源 URL 指向本机只读服务。它没有登录平台、访问受保护媒体路由、持久化学习记录或验证正式外部文档预览服务。没有全长逐帧解码 83 个视频，也没有主观音频质量、弱网、多浏览器、三角色全链或生产验收结论。媒体审计与 Nginx 修复各自独立管理，不能由本结果声称产品化目标全部完成。
