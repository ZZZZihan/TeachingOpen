# 教师管理范围撤销后的登录身份

原始 Pro 的缓存竞态假设在隔离合成基线 `a3f4e10` 实际复现：撤掉教师 `depart_ids`，模拟旧资料缓存迟到写回，原 token 仍读取原班作业。没有访问生产。

`ShiroRealm` 现在用已为账号状态与签名读取的实时用户行构造完整 `LoginUser`，不再以可缓存的个人资料作为授权范围。JWT 刷新规则、实时角色权限查询保持原合同；WebSocket 的班级判断原本就从实时用户行读取。

回归包含带屏障的迟到填充、同 token、组织/姓名/身份字段合同，以及真实 HTTP 的作业读写、文件元数据、字节 GET/HEAD 和拒绝后业务状态。原 Java 回归 1 项在基线上因旧 `class-a` 范围失败；修复与相关账号/授权套件 22 项通过。HTTP 前对照在迟到缓存下读取仍成功处按预期失败，且 `finally` 恢复合成范围。最终组合 HTTP、CI 与 Pro 结果由对应固定候选的交付证据提供，不用本单测代替独立验收。
