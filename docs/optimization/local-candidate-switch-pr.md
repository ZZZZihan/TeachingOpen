# 本地候选切换与回退

2026-10-03，基于 PR #30（`feature/local-backup-restore`，`fd1cd542ad71148580249b230ac4c1e2b7d66792`）。产品提交 `204a0e9b0419e4cf29908269d3c5e8ef2431f043`。本 Agent 自检，不是独立审核或人工验收。

## 改动和验收范围

此前运行服务直接引用 worktree 中的 JAR 和 `web/dist`，重建会改变候选文件；也没有统一保存上一候选或处理切换中断。本 PR 增加冻结候选包及 `activate / rollback / recover / stop / status`。校验全部产物摘要、相同表结构和真实进程/端口归属后，依次停止旧服务、启动并等待新服务就绪。失败时恢复上一候选；中断时保留切换意图，允许显式 recover。

新工具复制已有合成环境的前端代理，不是生产服务器。它要求本机可信包，保存提交和摘要但不证明构建来源，不执行数据库迁移。后端健康及前端 HTML 字节匹配仅为就绪检查，业务另外验收。命令与限制见 [BUILDING](../../api/BUILDING.md#冻结候选包切换与回退)。

## 真实演练

专用环境为 `.devspace/recovery-a`，端口 13336 / 16409 / 18131 / 18132。没有切换用户正在访问的 18102 或组合环境 18112。

候选 A 的前端来自 `c7d2a214cb4af410db30fb45746b8ca59096fc37`，在新的 `candidate-switch-previous` 工作区本轮重新构建成功，保留六条既有警告。依赖清单/锁文件与当前候选一致，复用已经安装的 node_modules，没有宣称重新干净安装。候选 B 前端来自 `b30f597524347de7de7f1ce2f22d5f9dc4ecc9dc`，复用已核对摘要的 dist；前端树与前一轮已构建的 `b7b536c` 一致。

两包后端都是 #24 的同一精确 JAR（`85f7746a3ae4b143f1a4ca4e5c043e11c81bf7d69f32c72b7dbaa190f6a0e85c`），本轮未重建。演练证明这两版前端组合及其后端进程的切换/回退，不能推断不同后端代码或数据库版本的降级兼容性。

| 行为 | 本次观察 |
| --- | --- |
| 初次启用 A | 后端/前端进程和监听 PID 符合包/运行目录，健康及 HTML 一致 |

**30/30 Python 单元检查**，其中新增 15 项，覆盖损坏产物、替换清单、结构不同、正常/失败/初次失败切换、恢复再次失败、显式中断恢复、并发锁、PID 重用、外来监听者、相同 JAR 的另一运行目录及自增计数器。

在 A 初始、B、主动回退 A、启动失败自动恢复 A、中断恢复 A 五个阶段，各执行 **26/26 真实业务检查（共 130 次检查）**：合成五账号登录、两名学生课程/作品、媒体 Cookie 下载、授权教师/管理员读取、匿名/异生/跨班教师拒绝及计数写入。没有将它们称为浏览器三角色闭环。结构化记录见 [证据清单](evidence/local-candidate-switch/manifest.json)。

## 数据核对与新发现

最初“除登录日志外所有表未变”的断言失败，实际变化为 `sys_log` 和 `teaching_work`，该断言不计为通过。检查控制器发现，`studentWorkInfo` 为增加浏览数调用通用 `updateById`，自动填充修改人/时间。五阶段检查只复原了浏览数，因此作品修改人/时间随读取改变。

已另做受控复现：学生 A 读取自己的作品后，修改人从 `fixture_admin` 变为 `fixture_student_a`，浏览数 +1，修改时间变化；随后把该探针前的三列精确复原。该业务缺陷未混入本 PR 的应用改动，登记为下一项独立修复。

本轮原始对比为 **67/69 表完全一致**；`sys_log` 从 3,009 行增至 3,071 行（含登录/退出及额外问题探针日志）。作品表除 `view_num/update_time/update_by` 外的内容，与恢复快照源逐列比较一致；附件字节未变。五阶段遗留的作品审计字段变化已明确保留，没有声称目标全库原样。原 `course-role-runtime` 全表和附件仍与原快照前一致，主源码工作区 5,634 项摘要不变。

这项发现不影响已观察到的候选切换和回退结果，但阻止把本轮表述为“所有业务表无变化”。产品化目标保持 active；下一项优先修复作品读取改写审计字段，再继续性能、依赖及真实认证浏览器完整流程。
