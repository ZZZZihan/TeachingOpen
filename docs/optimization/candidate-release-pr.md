# 冻结候选的 Linux 容器验证包

2026-10-05。本项基于发布 Nginx 修复 #66，增加可复制、可核对、可实际运行的私有候选包。此前本机候选依赖已有 macOS 服务和分散的构建目录，发布 Nginx 只单独验证过代理契约；本项将明确冻结的 Java 包、完整前端产物、代理配置与新建合成环境组合起来，通过真实 Nginx → Java → MySQL/Redis 验证代表性业务。

工具不会重新编译产品，不修改现有运行目录。显式指定可信集成 source、JAR 和 dist manifest 的摘要后，`create` 生成新的私有包，`verify` 核对不可变文件与固定 Compose 契约。原始 SQL 只提取 69 个空表；五账号、两班、三课程和素材来自已有自制夹具，凭据每次随机生成。生产数据、生产配置、真实师生信息不进入本包。

四个官方镜像按不可变 digest 固定为 Linux/arm64。API、数据库、Redis 只接内部网络；Nginx 同时接项目独占的入口网络，唯一发布端口为 `127.0.0.1:18190`。运行探针同时检查配置中的请求映射和 Docker 真正生效的映射，检查精确网络成员、镜像 ID、只读输入挂载及自有数据目录。

操作方法见 [CANDIDATE.md](../../deploy/CANDIDATE.md)。本分支只依赖 #66，并不包含全部产品修复与原生夹具工具；`--source` 需要明确指定集成候选。实际测量 source 为 `8ad3f13db83fe7b48063c99c0f5d33ad42358c67`，冻结 JAR SHA256 为 `9eb18d42d365dd4fba7044d57ed33aaa0fdb543f8468dd67c10c9dc83de05869`，dist manifest 为 `0b38b4690bac046186f3f4127eb8dc666aada7e2a413216a1a1a917f4bf2d120`，包含 4893 文件、211629143 字节。manifest 记录输入来源与摘要，但不是源码到产物的构建证明或签名。

## 实施、发现与修复

按用户指定，由 GPT-6.1-sol / ultra 子 Agent 分别实施工具、编写独立测试、准备运行探针、核对官方镜像和审阅契约，根 Agent 审查并执行真实容器。委派接口没有单独 Fast 参数。作者自检、独立测试、根 Agent 运行与用户人工验收分别记录。

- 离线独立负例发现 `format: true` 可被 Python 当作整数 1 接受，修复为精确整数类型判断。
- 第一次实际启动中，MySQL 完成初始化，但 mysqladmin 拒绝 `[client]` 内的 `local-infile=0`，依赖服务未能启动。将该选项移至 `[mysql]`，保留原健康判据；使用全新包验证。
- 第二次实际启动中，数据库健康、Java 启动成功，但只有 internal 网络的 Nginx 没有实际发布宿主端口。增加仅 Nginx 连接的入口 bridge，保留后端内部网络，并补充精确双网络及漂移拒绝测试。设计参照 [Docker 官方多网络说明](https://docs.docker.com/engine/network/#connecting-to-multiple-networks)。
- 提交前独立审阅发现运行探针会 chmod 已有报告父目录，修复为检查私有目录或创建新目录，拒绝不合要求的既有目录且保持其权限。

失败的 bundle、数据、日志和原始报告均留在本机私有目录，没有用新成功结果覆盖。首轮 SQL 测试 parser 和 placeholder 判断的两处测试侧错误，也由独立测试记录保留。

## 边界与后续

这次没有访问或改写 Z820 生产服务。2026-10-03 获取的私有生产来源副本继续在既有隔离环境中提供真实课程预览；本轮容器使用合成写入夹具，不能把两者的证据混合。真实副本的 83 个单元练习类型为空，创作写入仍需要自制课程。

本次不是 Z820 原机、生产部署、TLS、容量、普通浏览器登录或完整编辑器验收。合成 API 登录从自有 Redis 读取对应挑战值，仅用于受控接口验证；没有绕过浏览器登录或把该步骤称为人工验收。Python 草稿的 API 写入不代表 Python 编辑器保存链路。媒体字节检查不代表浏览器全程播放。

实际容器 MySQL 使用 Mac 宿主 bind 目录，`@@lower_case_table_names` 实测为 2。工具未强设此参数；本结果不证明大小写敏感 Linux 文件系统或 Z820 的表名行为。入口网络为普通 bridge，Nginx 具备该网络的正常出站能力；后端三服务没有加入它。正式目标环境应单独核对架构、文件系统、认证与 TLS 契约。Goal 继续 active，未远端合并或上线。
