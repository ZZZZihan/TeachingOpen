# 找回密码界面与流程修复

用户填写完整手机号后，原页面却把账号查询返回的脱敏手机号用于发送和校验；原修改密码请求还把密码放入 GET URL。本次让脱敏号码只作提示，三步请求使用真实输入，明确处理验证码有效、失败、已消费和修改结果不确定的不同状态。配合后端 [PR #69](https://github.com/ZZZZihan/TeachingOpen/pull/69) 切换，不单独上线旧后端。

## 界面与行为
