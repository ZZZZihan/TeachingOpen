# 附加作业保存失败恢复（M-05）

附加作业弹窗原先在 `finally` 中关闭，业务拒绝或网络错误都会丢失本次输入。现在复用 `CourseFormRecovery`：只有明确成功才关闭并刷新列表；失败保持表单、班级、说明和三个附件选择。验证、上传登记和保存期间禁止重复提交，关闭/切换使旧上传回调失效。网络结果未知时提示先核对列表，不自动发送第二次创建；尚未增加服务端创建幂等键。

已运行：`node --test web/tests/course-form-recovery.test.cjs` 30/30；`NODE_PATH=<task-cache>/node_modules node --test web/tests/course-upload-map-interaction.test.cjs` 16/16。后者执行真实 Vue 模板及 JUpload 状态/事件连线。

真实浏览器补验使用 [独立 Chrome runner](../../web/tests/additional-work-preview/README.md)，运行真实弹窗、JUpload、JModal、字典与班级组件，上传三个合成附件并完成 HTTP 文件登记，保存接口仅连接临时本机服务。HeadlessChrome 151.0.7922.34 的六个场景全部通过：固定旧版本 `a3f4e10` 在 403 后关闭并在重开后清空；修复版在 403、响应头前断连、响应截断后保留字段与附件，显式重试成功；延迟请求期间重复操作仅发出一次保存且成功回调一次。屏幕为 1440×1100、390×1100，窄屏包含顶部和附件区域的滚动截图。[原始报告及前后截图](../../evidence/m05-ui/README.md)随修复保留，包含源码 SHA-256、字段和真实请求计数。

边界：浏览器使用真实组件与合成 API，并非登录后的全站或真实数据库写入验收。响应头前裸连接重置时，单次点击在 Chrome 中共触发了 2–3 次 POST（集成候选 `a30018b903822b0d7a834e36434101026293cdda` 本次为两次）；这不是组件自动重试，但说明 UI 防重不能替代服务端幂等键。响应截断场景独立验证了一次请求失败后的内容恢复。未知结果提示保留，不把本项表述为端到端创建幂等。
