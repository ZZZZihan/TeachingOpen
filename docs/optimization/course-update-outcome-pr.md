# 课程更新结果与课程地图原子保存

编辑页面打开后，若课程或单元已被删除，旧接口仍返回成功；课程地图批量更新中夹有不存在的单元时，旧接口还会保存其他部分并报成功。旧精确 JAR 的 40 项检查重现了这两种行为。

产品提交 `2d937f9`，基于 #40。单条编辑现在检查实际更新结果，不存在时返回业务 404；缺少、空或空白 ID 返回业务 400。批量编辑先验证非空且不重复的 ID，再在同一事务中逐条核实更新结果，任一目标缺失或数据库写入失败都会回滚整个批次。正常更新、相同内容重试以及坐标零值继续有效。

保留现有 HTTP/JSON 契约：业务失败的 HTTP 仍为 200，JSON `success: false` 和 `code: 400/404`；既有匿名 HTTP 401 和角色拒绝业务 510 不变。没有修改表结构、角色规则、依赖或 UI。#42 表单据 `success` 判断是否关闭，因此能显示这类失败并保留内容。
