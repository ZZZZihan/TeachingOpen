# 可并行运行的独立本地环境

本 PR 将此前主工作区未提交的隔离环境工具整理到独立分支，补齐 worktree 和多环境支持。依赖 [PR #3](https://github.com/ZZZZihan/TeachingOpen/pull/3)，当前 base 为 `fix/disabled-third-login`；不包含后续课程/作业授权修复。

## 最终行为

- 从空目录创建 69 张表与五个合成账号，不导入上游业务 INSERT；数据库、缓存、附件和随机凭据各自隔离。
- 四个回环端口可配置，地址保存在运行目录的 `ports.json`，不再要求停止已有环境。旧运行目录继续使用原默认端口。
- 初始化目录可以位于项目 `.devspace/` 下，独立 worktree 不再受到固定源码层级判断影响；已有目录、占用端口和重复端口被拒绝。
- 后端启动前检查私有配置、数据库归属及合成账号，停止前核对 PID、JAR 路径和 profile。私有日志使用新文件，防止覆盖旧诊断。
- 数据库/Redis 停止前核对真实数据目录与端口，并等待监听关闭。再次启动使用原数据，不重新 seed。停止不依赖合成表内容，初始化中断后仍可对已确认归属的服务执行停止。
- 本地前端代理跟随该环境的后端端口，后端不可用时返回 502。请求日志不保存可能带令牌的路径、查询、正文或请求头。

## 实际验证（2026-10-02）

| 验证 | 结果 | 边界 |
| --- | --- | --- |
| 独立 worktree 构建 | Java 8、Maven 3.9.16，`clean package` 三模块 SUCCESS | 使用项目 Maven 缓存；Java 测试被父 POM 跳过 |
| DDL 提取检查 | 3/3 | 引号/分号处理、无重复/不完整定义、真实 69 表且不含 INSERT |
| 空目录初始化 | 成功 | 新运行目录、端口 13316/16389/18101/18102；原环境未停止 |
| 环境就绪 | [9/9](evidence/runtime-ready.json) | 核对服务/产物归属、结构、合成数据、课程读取和附件 |
| 生命周期及代理 | [11/11](evidence/runtime-lifecycle.json) | SPA 路由、实际 API 转发、停机 502、进程退出、数据保留、已有目录拒绝、原服务存活 |
| 重启后的环境 | [9/9](evidence/runtime-restarted.json) | 再次检查运行产物和合成数据；不是新增九项独立业务用例 |

第一次立即重启曾在端口预检查处实际失败：`EADDRINUSE`，尽管任务服务随后确认均已停止。再次执行启动→停止→立即启动复现同一错误。修复为与初始化一致的 `SO_REUSEADDR` 检查，并在停止命令中等待监听关闭；随后完整流程通过。没有用等待很久或跳过重启来规避该问题。

生命周期检查比较合成用户、课程、作业关键字段以及两份附件的摘要，重启前后一致；没有把该检查称为全库备份恢复演练。后续目标仍须单独完成备份恢复和发布回退。

使用现有前端 dist 仅验证本地服务器路由/代理能力，本 PR 没有修改 UI，也没有声称本轮重新完成浏览器业务验收。合成环境未准备真实媒体、完整菜单或真实师生数据。

## 复现与恢复

完整命令、工具清单、初始化、检查、停止和重启步骤见 [api/BUILDING.md](../../api/BUILDING.md)。运行目录、凭据、缓存和日志不进入 Git；只保留脱敏检查结果。若回退工具 PR，先用本分支脚本停止自己的环境并保留数据；旧版脚本不理解自定义端口，不用于停止本 PR 创建的非默认端口环境。

本轮创建的环境保留用于后续 PR 验证，临时前端代理已停止；原 18091 演示后端保持健康。源码与生产版本对应、权限、完整角色页面、媒体、容量和目标服务器运行均未由本 PR 证明。
