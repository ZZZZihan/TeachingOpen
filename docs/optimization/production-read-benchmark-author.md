# 私有内容副本只读 HTTP 基线作者记录

本结果为可复现、有限的本机只读基准工具。旧 `benchmark-local-http.py` 包含业务写入，不能在保留生产内容的私有副本上用于只读性能证据；新工具只请求匿名首页和一个公开课程图片封面，并把当前运行包、数据、硬件、逐次请求及结束状态一起保留。

分支为 `feature/production-read-benchmark`，基础为 PR #45 `feature/production-data-fixture` 的 `5f896ac572ec637bb3d4a92223d7c699e6b30182`。产品范围仅新增 `api/dev/benchmark-production-read.py`、`api/dev/production_read_benchmark.py`，补充 `api/BUILDING.md` 及本文；独立测试文件由测试 Agent 负责。既有 verifier、helper、Java、前端及构建产物均未修改。本工具依赖 PR #45 的私有副本来源与守卫；后续组合候选以实际执行时记录的 helper hash 为准。

验收行为是：

- 不合格快照、配置、运行包、进程或监听在请求前被拒绝，没有任意 URL/端口/负载调整入口。仅接受自有 `.devspace` 直接子目录的私有副本及绑定包；输出为其中新的权限 `600` 直接子文件。
- 只读 SQL 确定首页 `show_home=1` 集合及正向名称 LIKE 过滤集。全集/过滤严格比对，分页检查合法子集、唯一性、正确条数与 total/current/size/pages。由于既有接口没有 ORDER BY，有限额外分页预检只观察当次非重叠联合覆盖，不保证排序。
- 每个 HTTP 样本校验真实状态与语义；图片 GET 的完整长度/摘要、HEAD 的无正文与完整长度、Range 的 206/精确 Content-Range/长度/前缀摘要均要匹配。HTTP 200 搭配业务失败、错课程集合、错误分页或错误图片正文不能进入成功统计。
- 固定 3 轮 × 2 个 worker 配置 × 7 场景 × 24 计时样本，共 1008 次；预热 126 次另列，分页预检最多 50 次另列。固定旋转场景顺序、5 秒 socket 无活动超时、批次间 300 秒预算、响应字节上限限制工作量；并非硬墙钟终止保证。
- 每条失败保留耗时和固定错误码；统计分别提供全部样本与成功样本。批次最多 4 条，出现失败后停止安排后续请求，并尝试保存结束守卫与数据不变证据。
- 当前实际课程/单元计数通过本次只读 SQL 取得，初始清单计数另列。所选 7 张业务表前后行数/内容摘要相等；297 等素材数量随本次清单变化，全集只做文件集合/大小/mtime/类型/inode 元数据摘要，所选封面在读前确认大小且最多 16 MiB，再有限读取重算前后 SHA-256。
- 完整 JSON 不写名称、ID、内容、素材路径、查询或异常原文。报告绑定精确包、快照、源数据、脚本/helper 摘要以及硬件；不访问视频、受保护详情、学生文件、登录、Redis、远程链接，也不启动/停止服务。

作者仅执行新增脚本的编译、`--help` 以及 diff 检查，不操作运行服务、数据库或浏览器，不提交或推送。独立 Agent 的单元与临时 loopback 测试、根任务在授权私有副本和精确当前包上的实际测量，分别记录其真实结果；本文件不预写通过数或耗时。真实基线应从组合候选执行并绑定当时的脚本/helper 摘要，无需为 Python 工具重建 JAR 或前端。

审阅重点是守卫失败时零请求、SQL 期望集与接口现有契约、失败样本保留、partial-run finally 核对、图片 Range/HEAD 语义、有限读与隐私输出。快照守卫、配置文件和 HTTP 过程之间无法提供原子隔离；本机应独占该副本，避免其他人或任务同时改包、数据库、配置或素材。前后相等不能排除中途改后复原，也不保证操作日志、Redis或全部业务表不变。

这份证据仅支持共享开发机上的有限匿名 loopback 基线。没有 WAN、TLS、HTTP/2、浏览器渲染/视频播放、持续负载、饱和吞吐、跨机器复现、生产容量或人工验收结论。正式测量时应保留私有完整报告的文件摘要和权限，PR仅引用必要的脱敏汇总。
