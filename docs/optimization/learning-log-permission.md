# 课程阅读与班级浏览统计的授权边界

打开课程单元时，页面调用 `unitViewLog` 记录班级浏览统计。旧实现把 `userIdentity=2` 且没有课程所属班级成员关系的用户一律拒绝，因此管理员合法预览和共享课程阅读出现“本次学习记录暂未同步”。读取课程的授权实际允许这些行为，缺少的不是菜单权限。

本轮让统计入口先验证活跃账号、未删除的单元和课程，再复用 `TeachingAccessService.requireCourse` 的阅读授权。合法阅读但没有应计班级时返回 `NOT_APPLICABLE`，页面正常显示；不创建虚假的班级记录。原有身份条件、班级与单元终身去重、事务回滚、历史统计待核对 `409` 保留。普通学生也在返回不计数结果前验证课程和单元，跨班私有课程仍拒绝。

这是班级浏览统计的授权修复，不新增个人完成进度，不修改生产账号、角色或班级成员关系。无数据库迁移，无前端产物变化。

验收覆盖管理员和开发角色无班级预览、共享课程非成员阅读、正常班级记录与重开去重、匿名和跨班拒绝、删除课程/单元拒绝、无须统计和拒绝时业务数据/旧缓存不变，以及统计失败后重试。验证记录在本轮 PR 中更新；部署单独绑定合并提交和 JAR 摘要。

本地初始候选 JAR SHA-256 为 `762ea92400e507def0c4e9ede41193e0c0fa32a59f4a035cab4914fecbcf3717`。40 组核心 Java 测试 381/381 通过，其中统计事务回归 18 项；隔离真实后端的统计专项 54/54、既有课程阅读专项 80/80 通过。专项结束后核对业务行、媒体索引、旧 Redis 集合恢复；正常认证和请求审计保留。

使用原生产 JAR 在同一隔离环境复现管理员 HTTP 200 / 业务码 510 的失败；新候选通过同一触发条件。新旧 JAR 内容对比仅统计服务及其编译器生成类发生代码变化，公共模块嵌套 JAR 的文件内容逐项相同。未参与核心实现的 Agent 已技术复核，无本轮阻塞。完整 SPA 已验证管理员打开后不报错且统计不增、教师首次打开计数一次且重开不重复。CI、合并和线上结果以 PR 中后续交付记录为准，不把本地测试等同于上线。

首次 CI 中所有权限和并发断言通过，但收尾整表摘要因真实登录初始化测试账号 org_code 而失败。验证脚本将基线设在认证完成后、任何业务夹具修改前，继续完整核对 sys_user 等全部相关表；认证产生的正常资料初始化和审计保留。失败与修复后的证据分别保留。最终发布包按修正后的源码重建，并与上面的初始候选逐项比较运行内容；最终包摘要及合并提交在 PR 发布记录中绑定。
