# 社区作品可见性与互动授权

日期：2026-10-03。基于 PR #14 的 `1b5bfe930983ae8b35ef4967b0bf29546a963234`，独立分支 `fix/community-work-access`；前置改动不计入本次成果。

## 问题与最终行为

真实隔离后端上复现了匿名获取草稿、待批改、已批改、已删除作品及其附件地址/评论，匿名给草稿点赞、其他学生评论私人或不存在作品。`greatWork` 错把状态 2（已批改）作为精选，`leaderboard` 的 `>=3` 同时返回未知状态和已删除作品；公用管理查询还将教师评语和评分带进公开列表。旧候选 15/15 项重现与清理检查符合预期，证据见 `evidence/community-work/before.json`。

本次改动：

- 精选列表仅查状态 4；排行榜仅查状态 3/4，均在 SQL 分页前限定 `del_flag=0`。调用者提供状态或作者筛选不能扩大公开范围，公开列表移除教师评语/评分，私人管理列表继续保留。
- 详情、评论读取、点赞、评论写入先检查作品存在、未删除及访问范围。公开作品允许匿名阅读和点赞；私人作品限本人、负责该班且满足已有作者班级规则的教师、管理员/dev。评论写入仍须登录，作者仍由服务端指定。
- 三条原匿名资源路由改为可选 JWT 认证：未提供令牌可进入公开资源判断；提供令牌则执行已有完整 Shiro 验证，包括缓存和退出撤销，失败返回 HTTP 401，不静默降为匿名。资源拒绝沿用现有 HTTP 200 / 业务码 510 格式。
- 两套编辑器 `getWorkInfo` 带上本地登录令牌，无令牌时不发送空认证头。作品评论请求被拒绝或网络失败时结束加载并保留原列表与分页，允许重试同一页。

以上判断在返回作品模型/文件地址、读取评论、修改计数或写入评论之前执行。作品撤回后下一次匿名请求立即被拒绝，历史点赞缓存不会绕过判断。
