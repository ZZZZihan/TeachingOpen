# 运行依赖维护与迁移顺序

维护基线：2026-10-10。本轮先关闭已确认的权限和内容注入路径，并更换实际启用的富文本编辑器；以下框架迁移是后续独立 PR 的实施计划，不能视为已经完成。

## 当前发布门禁

- 富文本使用固定版本 Tiptap 核心与扩展（MIT）、DOMPurify（采用 Apache-2.0 许可选项）及后端 jsoup（MIT）。不引入需要购买许可的扩展；保留各依赖的许可证和版权声明。
- `ci/check_richtext_dependencies.py` 同时核对编辑器的锁定依赖图和生产构建实际进入各页面代码块的依赖包。Webpack 输出精简清单并绑定锁文件摘要；CI 在生产构建之后获取 npm 当前公告，未获例外的 high/critical、缺失/过期产物清单、锁文件缺项或公告获取失败都会阻断 PR。已移除的 TinyMCE 及其包装器不得重新进入锁文件。
- 确需例外时，在 `ci/richtext-dependency-policy.json` 写入具体包、公告 URL、负责人、可验证的不可达原因或补偿措施及到期日，随独立 PR 复核；例外过期自动阻断。不能用“项目暂时不升级”作为整组依赖的豁免。
- 前端门禁覆盖实际生产浏览器包，并非全应用漏洞清零证明。旧组件把构建工具列在 production dependencies，故依据实际构建模块识别浏览器依赖；聚合 high/critical 只有其实际进入浏览器的依赖包含对应高危公告时才阻断。后端 JAR、预打包库内部未单独声明的嵌入依赖及未来加载的外部脚本仍须单独盘点。
- 本轮同时将 Axios 更新至 0.34.0，并更新兼容范围内的 Lodash 锁定版本，消除当前公告命中的实际请求库及模板处理风险。保留两条精确的临时例外：Swiper options 与 lodash.pick 字段路径均由源码常量提供，当前未将不可信内容传入公告要求的参数位置。负责人为仓库维护者 `ZZZZihan`，到期日为 **2026-10-24**；详情与公告在策略 JSON，到期或调用边界改变必须修复并移除例外，不能续期而不复核。
- 每次编辑器或清洗规则变更必须通过 Java 清洗、真实接口保存/读取、实际编辑器输入/粘贴/上传/重开及公开展示回归。合法富文本不得因清洗失去基本编辑功能。

## 后续 PR 与验收门槛

负责人按仓库模块维护职责分配，实际接手的实施者在对应 PR 署名。生产迁移和数据操作仍须单独授权。开始每阶段时重新核对官方支持版本，避免把当前计划中的版本线当成长期有效的支持承诺。

| 顺序 | 范围与责任 | 前置与实施 | 完成标准 |
| --- | --- | --- | --- |
| 1 | 前后端维护者：依赖可达性清单 | 固定现有构建产物，列出实际浏览器模块及 JAR 运行库；将构建工具移回开发依赖，逐项复核高危公告 | 每个运行时可达高危项有修复 PR，或具体负责人、原因和到期日；不得把无评估条目静默加入例外 |
| 2 | 后端维护者：JDK / Spring / 持久层 | 先建立 Java 17+ 兼容构建；中间版本只作迁移桥梁；最终选择实施时仍受支持的 Spring Boot 版本，调整 Jakarta Servlet、验证、ORM及驱动 | 在新旧候选上对照注册、登录、撤销、恢复密码、角色缓存、文件、作业和 SQL 事务；数据库结构若改变，另有迁移和回退审查 |
| 3 | 后端维护者：认证框架 | 在受支持 JDK / Servlet 基础上选择受支持 Shiro 线或评估 Spring Security；保留已有 JWT 和撤销契约直至显式迁移 | 编码路径、分派、匿名/可选登录、冻结、改密、授权变更立即生效等实际容器回归全过；不可仅以编译成功验收 |
| 4 | 前端维护者：Vue 3 与构建工具 | 逐页迁移表单装饰器、Ant Design Vue、路由、状态管理和旧组件；富文本核心已与 Vue 包装器解耦 | 师生和管理员主路径、课程附件/地图、作业、资讯及无障碍键盘交互通过；资产体积门禁通过，无旧 Vue 运行时残留 |
| 5 | 发布维护者：组合候选 | 合并以上已验收 PR，重跑同一候选包的全部检查 | CI、隔离真实运行、人工验收和生产部署分别有证据；任何依赖例外到期均阻止发布 |

本轮保留的 Vue 2.7.16、Spring Boot 2.1.3 和 Shiro 1.13.0 均属于已结束维护的版本线。Vue 官方确认 Vue 2 在 2023-12-31 EOL；Spring 官方确认 2.1.x 在 2020-11-01 结束维护；Shiro 当前页面同时标注 1.x 与 2.x EOL，不能把升级到 2.x 本身作为最终维护目标。

官方依据：[Vue 2 EOL](https://v2.vuejs.org/eol/)、[Spring Boot 2.1 EOL](https://spring.io/blog/2019/12/10/spring-boot-2-1-x-eol-november-1st-2020/)、[Apache Shiro 版本声明](https://shiro.apache.org/about.html)、[原 TinyMCE 公告](https://github.com/tinymce/tinymce/security/advisories/GHSA-vg35-5wq7-3x7w)。
