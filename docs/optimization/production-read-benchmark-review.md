## 结论与发现

冻结版本没有剩余阻断项。新增 51 项测试覆盖实际 HTTP 响应、统计分母、失败退出、输出保护与所声明的保全范围。

源码审阅发现连接关闭异常可能逃出 `run_sample`，使采样批次的已完成结果不能进入报告。作者修复为保留失败样本并返回固定 `http_transport_failure` 错误码；关闭异常和并发批次失败均有回归测试。

控制器 `getHomeCourse` 使用 `show_home=1` 和可选过滤条件，没有 `ORDER BY`。测试允许合法不同记录顺序，分页要求 SQL 可见集合中的合法子集、正确条数、无重复及准确页码信息。另以预检各页联合覆盖且互不重复观察当次完整分区。此结果不宣称 API 提供稳定排序。实体 `courseType`、`courseCategory` 为字符串，`showHome` 为布尔值，`delFlag` 为可空整数，测试据此检查字段类型和 SQL 值。

## 验证范围

- 首页 HTTP 200 仍须具有布尔 `success=true`、成功业务码、正确总数、页码、页大小、页数、记录集合和 SQL 字段。错误状态、HTML、业务失败、未知/重复/缺失记录、错误标志和过滤集合都会失败。
- 媒体 GET 检查状态、MIME、完整长度、Range 支持及完整哈希；HEAD 检查完整长度和空响应体；Range 检查 206、精确 `Content-Range`、部分长度和前缀哈希。伪成功响应、错 Range、错字节和错 MIME 均拒绝。
- 真实 HTTP 单元测试仅绑定临时自有 `127.0.0.1:0` 监听器；观察无 Cookie、Authorization 或访问令牌。环境代理不会接管连接，重定向只产生一次失败请求，不跟随目标。任意外部 URL、受保护路线和写方法在建立连接前拒绝。
- JSON/Range 响应读取上限包含一个越界哨兵；媒体清单大小在打开文件前受限制。连接关闭、超时和验证失败保持计时样本及固定错误码，私密异常文本不会进入样本、报告或标准输出。
- 最近秩 p95 使用全部尝试的个体延迟。失败样本保留在总体分母和总体延迟中，成功延迟另列；全失败或空集合使用零计数与空分位值，不生成虚假成功指标。
- 调度计划保持 3 轮 × 2 种并发 × 7 场景 × 24 次计时，共 1008 次；每个单元 3 次预热，共 126 次。预检计数单独列出。失败保留当前批次全部已完成样本并停止后续调度；预算耗尽也停止调度。
- 仅接受直接位于私有运行目录中的全新输出；已有文件、符号链接及其目标保持原内容。新 JSON 的权限为 600；报告与标准输出不含内存中的课程名、ID、资产相对路径、运行目录路径或异常详情。
- 守卫失败产生零 HTTP；结束守卫失效时不再发起 SQL 快照。部分 HTTP 失败且结束守卫仍通过时，仍完成业务快照、资产元数据和所选封面的检查；业务变动、最终快照不可用、资产元数据变动或封面字节变动均导致整体失败。
- 场景构建保留真实当次 SQL 行数与 manifest 行数的区别，过滤值以十六进制 SQL 字面量传入；仅使用 SELECT。只选择可见课程引用且位于清单中的本地封面；其他远程资源和未列入清单的资源不会作为 HTTP 目标。

## 证据限制

此回归只证明冻结工具在所覆盖分支下的行为。临时 HTTP fixture 不证明候选 JAR 的真实响应，也不证明实际数据集、机器或生产环境性能。

工具的守卫仍依赖既有 `verify-production-content.py` 的私有副本身份与配置检查。业务保全范围是七张指定业务表；全资产集合比较文件清单、大小、mtime、mode 和 inode 等元数据，不重新哈希多 GB 的全部内容；选定封面比较前后完整字节哈希。运行报告必须保留这些限制。

五秒为 socket 的等待超时；测量预算在批次之间检查，并非强制的整体请求截止时间。预检、SQL、文件检查、语义校验和报告写入不属于计时样本。共享开发机器上的有限本机读取不能得出长期负载、饱和点或生产容量结论。
