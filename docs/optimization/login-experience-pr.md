# 登录与会话体验

本项独立基于课程发现 PR #7（`4dfcec81b0742de480c7631264f89b932893e23f`）。前端运行于隔离的 18112，当前代理到 PR #20 的 18111 后端；原 18102 公共预览保持不变。首轮浏览器证据使用 PR #18，见下文区分。

## 改动结果

登录入口沿用公共页的白色页头、墨色内容区、细边框和克制的红色操作色。补齐账号、密码、验证码的原生标签、密码自动填充属性、显隐按钮、键盘提交、焦点提示和手机排版；保留已有注册开关和找回密码入口。移除原先没有实现对应存储策略的“自动登陆”选项，保留现有登录有效期策略。

验证码显示加载、失败和可重试状态，禁止无验证码图片时提交；登录期间防重复提交，失败后保留账号并刷新已消费的验证码。登录错误在表单内展示，网络故障使用可操作的中文提示，旧请求不能覆盖新验证码。删除登录参数和 HTTP 错误处理中的凭证输出，以及本页面不可达的旧登录方式代码；保留其他页面可能使用的旧认证 action/API。

登录后恢复站内目标路径的 query/hash，并拒绝外站、反斜杠、控制字符、编码绕过和登录页循环目标。公共课程和首页不再被权限接口短暂故障阻断；受保护页面权限加载失败进入重试页，保留登录信息。空菜单是有效结果，权限加载合并并发请求，登出或换账号后迟到的权限结果被丢弃。

同一过期会话只提示一次，先清理本地令牌、角色、动态路由和按钮权限，让用户选择留在原页复制未保存内容或重新登录，取消原先的定时强制刷新。旧账号迟到的 401 不会注销新账号。手动退出在页面刷新后也能读取持久化令牌发给后端，本地状态立即撤销，后端退出请求最多等待 8 秒。离线情况下无法证明服务端凭证已撤销，未宣称这一点。

用户布局兼容现有找回密码页，移除旧页面 130% 宽度和负边距造成的手机横向溢出；未改变短信或密码重置业务。
