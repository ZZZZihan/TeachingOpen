## 本轮新增的只读结果

由指定 GPT-6.1-sol / ultra 子 Agent 执行服务器强制 READ ONLY 事务内的 SQL 和课程素材文件属性核对；主 Agent 复核聚合结果及范围。本轮不是独立浏览器验收。

- 297/297 份清单素材存在且大小匹配，资源引用集合与清单相同，没有缺失或大小不符。本轮没有重新计算约 5.94 GB 内容的哈希；原获取时的逐文件哈希证据不能写成本轮重新执行。
- 83 个单元均配置上传型视频，引用 83 份 MP4；均有 HTML 正文和单元封面。45 个单元配置 PDF 课程资料，83 个单元配置 `.md` 后缀教案文件。这里确认字段、引用与文件属性，没有播放视频或打开文档，文件后缀也不证明实际内容格式。
- 83 个单元的练习类型均为空，案例与预设作业字段均空，附加作业记录为零。因此这份真实数据不能覆盖 Scratch、ScratchJr、Python 的指定练习及保存、重开、提交链路；三角色自制测试课程仍需保留。
- 83 个单元均能关联到现有课程；5 门课程中有 2 门没有单元。4 条历史课程—班级关系同时缺少对应课程和班级，3 条用户—班级关系同时缺少对应用户和班级。保留原事实，没有补造关联或清理数据；不能据此断言当前 5 门课程都受影响。
- 9 张选定业务及关联表在检查前后的行数与内容摘要相同。不是全部 69 张表的全库一致性结论；没有数据库写入、Redis 操作、服务重启、学生文件读取、登录或浏览器操作。

完整统计见 [aggregate.json](evidence/production-copy-coverage-20261005/aggregate.json)，执行方法和限制见 [独立检查记录](evidence/production-copy-coverage-20261005/review.md)。此前真实副本匿名课程列表、分页、筛选和封面读取 12/12 是已有证据，未计入本轮新增检查。

## 如何用于后续工作

真实副本用于课程页面、长正文、实际资源引用和媒体兼容性；自制课程用于真实数据未覆盖的编辑器、角色和写入故障流程。对这份保留副本继续优先只读，写入与清理使用独立可恢复的测试数据。历史悬空关联先作为数据质量问题保留，需要实证其用户可见影响后再决定代码或数据修复，不能自动扩大生产写入授权。

并行的[性能、恢复与维护证据审阅](evidence/production-copy-coverage-20261005/candidate-gap-review.md)确认：已有有限 HTTP 读写性能、首页按需加载对照、数据库/附件/云变量恢复及候选回退演练，仍可在原声明范围内成立。本轮没有重复这些测试。后续有价值的增量是绑定当前精确包和上述真实数据的有限只读性能样本，以及更新当前依赖维护与发布风险清单；完整认证三角色、编辑器流程、人工视觉和目标环境验收仍分别待完成。

本轮只更新现有管理 PR #1 的证据和计划，不为尚未实施的发现建立空 PR。后续每个实际修复或功能继续独立 PR。Goal 保持 active，未合并、发布或部署。
