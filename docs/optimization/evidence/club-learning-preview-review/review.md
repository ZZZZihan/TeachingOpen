## 真实性、语义与隐私边界

首页主项目明确写“可操作演示”；声音与桥梁写“概念演示”，按钮打开项目想法，弹窗说明目前只有想法，并提供进入几何画室的出口。未发现把两个概念项目包装成完整课程的入口。

学习页参数实际决定 SVG 多边形边数、重复次数、旋转和颜色。任务勾选、步骤完成与创作台进度是用户自己标记的练习记录；没有声称由系统判定技能掌握、后端课程完成率或教师验收。建议文字由固定规则分支生成，学习页明示“规则建议演示 · 非老师反馈”，创作台也明示固定规则建议演示。

仅引用相邻的本地 CSS 和 JS，图形由内联 SVG 生成。检索出的 HTTP 字符串是 SVG XML 命名空间；未发现外部字体、图片、CDN、fetch、XMLHttpRequest、WebSocket、账号、Cookie 或产品 API 调用。标题与笔记进入 HTML 模板前转义，颜色只从固定调色板恢复。存储只读写原型专用 key `teachingopen-club-preview-v1`，没有枚举、清空或删除同源其他记录。
