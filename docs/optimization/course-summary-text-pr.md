## 改动及原因

既有 Autoprefixer 6.7.7 会删除三行截断所需的 `-webkit-box-orient: vertical`，该版本也不支持 `ignore next`。仅在摘要规则内关闭该转换，并加三行高度上限；不改全局构建配置或依赖。

摘要先去除原始标签、注释及 script/style 块，再一次解码常用命名实体及合法 Unicode 数字实体。未知/非法实体保留，双重转义不递归展开。仍使用 Vue 文本插值；编码后的标签不会进入 HTML 执行路径。按钮传出原课程对象，完整介绍保留原内容。

代码与自检由 GPT-6.1-sol / Ultra 子 Agent 完成；root 负责组合构建、真实副本浏览器复验与交付。Fast 没有可配置的工具参数，未声明已开启。另一个测试 Agent 只读审查最终提交与已有构建：未发现阻断问题，确认实际 CSS 保留三行声明、既有先加载的 polyfill 覆盖 String.fromCodePoint。该审查没有重跑测试、浏览器或读取生产原文，不替代真实页面复验。
