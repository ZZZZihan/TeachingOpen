# 初高中社团学习体验：阶段目标与方向原型

记录日期：2026-10-05。当前决定：用户查看原型后要求恢复原版，本次视觉方向撤回，不再按下述方案继续正式接入。已有实现和证据保留，正式产品未应用该原型；下文保留原阶段目标作为历史记录。

## 用户与目标

主要用户是天津初高中学生，使用场景以社团、课后活动为主，项目制且节奏较自由。学生进入平台应能找到想做的作品，动手尝试，下次继续，并根据老师建议改进。天津工业大学识别继续保留，但首页主要展示创作成果和可采取的行动，减少高校官网的宣传版面。

本阶段先验证公开首页、学生创作台、一个代表性项目学习页。先完成可点击、有真实交互的方向样稿，供用户审阅，再按反馈接入现有产品；不在方向尚未确认时批量扩展全站。代理人自检、独立代码审查、用户审美判断、真实学生试用分别记录。

## 参考网站与取舍

以下为 2026-10-05 对官方页面的实际访问。借鉴信息组织和学习路径，不复制第三方品牌、图片或学生作品。

| 官方参考 | 本次观察 | 对本项目的选择 |
| --- | --- | --- |
| [Raspberry Pi Projects](https://projects.raspberrypi.org/en) | 首页先提供游戏、艺术、音乐等兴趣入口，再提供工具入口；机构信息不替代项目入口。 | 用作品和兴趣引导学生，工具作为辅助说明。 |
| [Art 项目列表](https://projects.raspberrypi.org/en/interests/art) | 项目结果图配一句具体的创作目标；可按工具和难度筛选。 | 自制成果预览；当前数据没有难度字段，不照搬难度筛选。 |
| [Powerful patterns](https://projects.raspberrypi.org/en/projects/editor-powerful-patterns/landing) | 项目页先说明能做出什么，提供可运行示例和明确开始入口。 | 主项目提供实时可编辑画布，说明一个可完成的小目标与延伸方向。 |
| [Scratch](https://scratch.mit.edu/) | 可观察到 Create / Explore / Ideas 导航与作品、工作室分区；本次项目图片未完整加载。 | 借鉴创作与探索并重；不把未完整加载页面当成完整视觉评审证据。 |
| [Code.org 学生页](https://code.org/en-US/students) | 明确区分 5–11 岁与 11 岁以上入口；强调应用、游戏、动画等成果，提供课外活动资源。 | 初高中用清晰、轻松但不低幼的表达，不复制成人培训营销页面。 |

原型采用作品画廊与动手画布：克制的底色、清楚的字体层次、少量强调色和原创几何图形。视觉是否符合用户期待尚需反馈，不能通过自动化测试代替。

## 原型交付边界

目录为 `design/club-learning-preview/`，独立 HTML/CSS/JavaScript，三个哈希路由。只使用原创演示内容，不引用私有课程正文、学生数据、教师答案或生产图片。一个几何创作项目可实际交互，其余主题只展示明确标注的项目构想。

本地保存仅表示当前浏览器保存原型作品，不代表服务器保存、账号登录、教师提交、作品公开或多人协作。任何反馈范例必须标明示例；不杜撰项目完成百分比、连续学习天数、教师消息或机构合作声明。
